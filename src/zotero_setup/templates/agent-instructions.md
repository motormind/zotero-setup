## Zotero / references

- References live in a Zotero group library. Settings are in `.zotero.toml`; the API key is in `.env` (never print it, never commit it).
- `references.bib` is generated by `zt pull` - do not edit it by hand.
- To add a paper: append its DOI / arXiv ID to `papers/ids.txt`, run `zt push --dry-run`, then `zt push`.
- To search: `zt search <terms>` or the tools of the `zotero` MCP server.
- Always ask before writing to Zotero (`zt push`, MCP write tools).
